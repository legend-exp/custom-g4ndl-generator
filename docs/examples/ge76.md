# Example: Ge-76 capture with n_TOF data

The files are in `examples/` of the repository. The config scales the Ge-76
capture cross section by 1.68 and replaces 10⁻⁵ eV – 52 keV with the n_TOF
measurement ([Phys. Rev. C 104, 044610](https://journals.aps.org/prc/abstract/10.1103/PhysRevC.104.044610)).
Below 0.026 eV, the table continues the first n_TOF point with 1/v.

```{literalinclude} ../../examples/ge76_ntof.yaml
:language: yaml
:start-at: customization
```

```bash
cd examples
custom-g4ndl ge76_ntof.yaml --source G4NDL.4.7.1
```

## Comparison plot

`docs/examples/draw_comparison.py` makes the library from G4NDL 4.7.1 and plots the
cross section before and after. The black points are the measurement of
Bhike et al. ([Phys. Lett. B 741 (2015) 150](https://doi.org/10.1016/j.physletb.2014.12.004),
EXFOR 14469). They are the reason for the scale factor 1.68 above the n_TOF
range.
